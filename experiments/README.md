assumptions and a stopping condition. Synthetic failures precede live mutation;
never break the live machine to prove that a recovery mechanism works.

candidates, healthy/unknown components, proposed changes, preservation and
verification requirements, actual results, and retained learning. Fictional
confirmation applies only to the stipulated model, never to a real installation.
